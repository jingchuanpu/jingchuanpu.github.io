Normal Distribution Calculator

Find a probability from a value of X (what R’s pnorm does), or find the value of X from a probability (what R’s qnorm does).

Parameters

How to use this page

  • Set the mean and standard deviation of X.
  • Choose the type of calculation: value → probability, or probability → value.
  • Pick the region you care about under Probability Options and type your numbers in Input.
  • In value → probability mode you can also drag the edge of the blue area on the graph.
  • The blue area always equals the probability. The R code below the result gives the same answer in R.
  • For the two-value options in probability → value mode, the probability is split equally between the two tails, so q1 and q2 sit at the same distance from the mean.

Tip: drag the edge of the blue area to change the value.
