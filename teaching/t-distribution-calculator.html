t Distribution Calculator

Find a probability from a value of T (what R’s pt does), or find the value of T from a probability (what R’s qt does).

Parameters

How to use this page

  • Set the degrees of freedom (df). For a one-sample t test, df = n − 1.
  • Choose the type of calculation: value → probability, or probability → value.
  • Pick the region you care about under Probability Options and type your numbers in Input.
  • In value → probability mode you can also drag the edge of the blue area on the graph.
  • The blue area always equals the probability. The R code below the result gives the same answer in R.
  • For the two-value options in probability → value mode, the probability is split equally between the two tails, so q1 = −q2.
  • Tick “Show the standard normal curve” to see that the t curve has heavier tails, and that it gets closer to the normal curve as df grows.
